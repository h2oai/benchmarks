# Logos in the hero's charts

The hero (#139) marks each company on its benchmark row with its logo. The marks belong to their owners; they appear
only to identify each company's entry on a public leaderboard (nominative use), and no endorsement is implied.

The files are vendored, so the page loads nothing from other sites. Each SVG was stripped to plain shapes for `<img>`
use (no scripts, styles, metadata or external references). The design that chose them is the "Benchmarks hero"
canvas, version `1793253107-dc37`.
